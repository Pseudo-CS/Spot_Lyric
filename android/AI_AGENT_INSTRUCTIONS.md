# AI Agent Instructions

All AI agents working on this project **must**:
1. Update `CHANGELOG.md` for every change (code, config, docs). Use the current date and a short, clear entry.
2. Update `TODO.md` when adding, starting, or completing tasks.
3. Avoid adding new documentation files unless explicitly requested. Only `README.md`, `CHANGELOG.md`, and this file should exist as docs.
4. Delete implementation plan files in the `plans/` directory once all of their associated tasks have been successfully executed and marked off as completed in `TODO.md`.
5. Do not make any git commits or push code to the remote repository unless explicitly instructed by the user.
